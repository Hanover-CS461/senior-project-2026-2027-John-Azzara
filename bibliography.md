# College Coach Basketball Sim
The goal of this project is to create a basketball manager/coach simulator. The user will select a college team and their task is to use recruiting, the transfer portal, player development, scouting, and staff to build the best program they can.
The central idea is doing every aspect of running a college basketball program but not actually controlling the players in game. The user will be expected to set their team tactics up and find the best linup and setup for each gameday to defeat their opponents.
### Inspired by Football Manager
Football Manager (Also known as Soccer Manager in North America) Football Manager is a long‑running sports management simulation where players control every strategic aspect of running a football club like scouting, transfers, tactics, player development, and match‑day decisions, without directly controlling the athletes on the field. 
### Web-App Based
The initial idea is to host it through a web app so there is no downloading that needs to take place and applying updates can be easily done. After some development a mobile app may be introduced but not 100% a locked in idea as of now.
