# Game Simulation Logic Tutorial

Welcome to the tutorial on how a single basketball game is simulated inside a college basketball management game.

---

## 🎯 Learning Objectives
By the end of this tutorial, you will understand:

- How possessions are simulated
- How shot types are chosen
- How shot success is calculated
- How fatigue affects players
- How coaching tactics influence outcomes
- How box scores are generated

---

## 👥 Target Audience
This tutorial is intended for:

- Students building sports simulation games
- Developers new to probability-based game engines
- Anyone preparing to implement basketball game logic

---

## 🧰 Prerequisites
You should already have:

- Basic programming experience (JavaScript recommended)
- Node.js installed
- A working GitHub Pages setup
- A `/docs/tutorial` directory in your repo
