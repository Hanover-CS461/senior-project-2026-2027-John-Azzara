# Game Simulation Logic Tutorial
Welcome to the tutorial on **how a single game is simulated** inside a college basketball management game.  
This tutorial explains the core logic your game uses to decide **who wins**, **how players perform**, and **how stats are generated**.

---

## 🎯 Learning Objectives
By the end of this tutorial, you will be able to:

- Understand the possession-based simulation model.
- Implement fatigue, randomness, and rating-based outcomes.
- Generate realistic box scores from simulation events.
- Apply coaching/tactic modifiers to influence game flow.
- Follow a complete game simulation from start to finish.

---

## 👥 Target Audience
This tutorial is designed for:

- Students building sports simulation games.
- Developers new to probability-based game engines.
- Anyone preparing to implement a basketball game simulator.

---

## 🧰 Prerequisites
You should already have:

- Basic programming experience (JavaScript or similar).
- Node.js installed.
- A working project folder with a `/docs/tutorial` directory.
- Ability to run simple scripts from the terminal.
