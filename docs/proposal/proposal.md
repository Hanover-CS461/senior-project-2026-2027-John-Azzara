# College Basketball Manager Game  
### Senior Project Proposal  
### John Azzara

## Overview
This project is a college basketball management simulation game where players take on the role of a head coach and program director. The user manages recruiting, training, scheduling, player development, and in‑game strategy. The goal is to create a realistic and engaging simulation of running a college basketball program.

## Objectives
- Build a functioning simulation engine for team and player performance.
- Implement recruiting logic based on player attributes, interest, and program prestige.
- Create a user interface for managing roster, training, and scheduling.
- Simulate full games with statistical outputs.
- Provide season progression: tournaments, awards, player development, and off‑season recruiting.
